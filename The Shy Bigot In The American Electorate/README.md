# ANES Time Series Cumulative Data

## Data Source
The raw data for this analysis is provided by the American National Election Studies (ANES). 
You can download the full dataset here: 
[https://electionstudies.org/data-center/anes-time-series-cumulative-data-file/](https://electionstudies.org/data-center/anes-time-series-cumulative-data-file/)

## Note on Repository Size
This repository excludes the primary CSV file to maintain performance and comply with GitHub's file size limits (100MB). 

To reproduce the analysis in `viz.ipynb`, please download the dataset from the link above and place it in this directory. The code expects the file path to remain consistent with the original naming convention.
